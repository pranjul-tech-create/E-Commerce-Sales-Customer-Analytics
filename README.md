# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview
This project is an Excel-based dashboard created to analyze e-commerce sales, profit, orders, customers, products, and state-wise performance.

## Tools Used
- Microsoft Excel
- Excel formulas
- Charts
- Data analysis

## Dashboard Features
- Total Sales
- Total Orders
- Total Profit
- Total Customers
- Average Order Value
- Profit Margin
- Monthly Sales Trend
- Sales by Category
- Top 10 Products by Sales
- Sales by State
- Customer Analytics

## File
The Excel workbook contains raw data, analysis sheets, customer analytics, and the final dashboard.
